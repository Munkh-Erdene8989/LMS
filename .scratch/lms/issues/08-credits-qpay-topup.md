# 08: Кредит ledger ба QPay цэнэглэлт

**What to build:** Хэрэглэгч админаас тохируулсан кредит багцыг сонгож QPay нэхэмжлэх (QR + банкны апп deeplink) авч төлнө. Төлбөр баталгаажмагц кредит нэмэгдэнэ. Хэрэглэгч баланс, lot бүрийн дуусах хугацаа, бүх гүйлгээний түүхийг харна. Админд л харагдах 100₮ туршилтын багц бий.

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] Append-only ledger: `topup`, `subscription_grant`, `spend`, `expire`, `admin_adjust`
- [ ] Credit lot бүр дуусах хугацаатай (тохиргооноос, анхдагч 12 сар)
- [ ] Credits модуль нь балансыг өөрчлөх цорын ганц нэвтрэх цэг
- [ ] Мөнгөн дүн бүхэл тоогоор
- [ ] QPay adapter: нэхэмжлэх үүсгэх, callback, payment check
- [ ] Callback ирэхэд QPay API-аар дахин шалгана; idempotent (давхар callback кредит давхарлахгүй)
- [ ] Callback ирээгүй үед хэрэглэгч "Төлбөр шалгах" дарж болно
- [ ] Админ кредит багц CRUD; 100₮ test багц зөвхөн админд, гүйлгээ `is_test`
- [ ] Баланс, lot, түүх UI
- [ ] Баримтын мэдэгдэл
- [ ] Integration тест: давхар callback, хуурамч callback (шалгалт амжилтгүй), test flag
