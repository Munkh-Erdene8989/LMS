# 09: Худалдан авалт (lesson / курс), эрх ба багшийн орлого

**What to build:** Хэрэглэгч курсийн хуудаснаас lesson-ыг ширхэгээр эсвэл курсийг бүтнээр кредитээр авна. Курсийн үнээс тухайн курсийн lesson-д аль хэдийн зарцуулсан кредит хасагдана. Буцаалтгүй гэдгийг баталгаажуулахаас өмнө харуулна. Худалдан авалт эрх (entitlement) үүсгэж, багшийн орлогыг шимтгэл хассан дүнгээр бичнэ (attribution анхдагч нь platform-sourced, 40%).

**Blocked by:** 07, 08

**Status:** ready-for-agent

- [ ] Нэг DB transaction: FIFO кредит хасах + entitlement + багшийн орлого
- [ ] Нэг lesson-ыг давхар авах боломжгүй
- [ ] Курсийн үнэ = max(0, курсийн үнэ − аль хэдийн зарцуулсан)
- [ ] Багшийн орлого = кредит × худалдан авах үеийн ₮ үнэ × (1 − шимтгэл); үнэ, шимтгэлийг бичилтэд хадгална
- [ ] Багшийн орлогын ledger: `sale_earning`, `payout`, `admin_adjust`
- [ ] Entitlement шалгалт: контент (PDF URL г.м) зөвхөн эрхтэй эсвэл preview үед гарна
- [ ] Багш өөрийн, админ бүх курсийг үзнэ
- [ ] Буцаалтгүй анхааруулга + баталгаажуулалт
- [ ] Кредит хүрэлцэхгүй үед цэнэглэх урсгал руу чиглүүлнэ
- [ ] Integration тест: курсийн хасалт, хүрэлцээгүй баланс, зэрэг (concurrent) худалдан авалт, шимтгэлийн тооцоо
