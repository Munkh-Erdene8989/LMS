# 05: Багшийн өргөдөл

**What to build:** Утсаа баталгаажуулсан хэрэглэгч багшийн өргөдөл (нэр, намтар, чиглэл, жишээ контентын линк, банкны данс) гаргаж, багшийн гэрээний одоогийн хувилбарыг зөвшөөрнө. Админ дараалалд шалгаж, зөвшөөрөх эсвэл шалтгаантай буцаана. Хэрэглэгч төлөв, тайлбарыг харж, засаж дахин илгээнэ.

**Blocked by:** 03, 04

**Status:** ready-for-agent

- [ ] Банкны данс (банк, дансны дугаар, эзэмшигч) хадгалагдана, багш засаж болно
- [ ] Админы дараалал: зөвшөөрөх → teacher role, буцаах → шалтгаан
