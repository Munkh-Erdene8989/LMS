# 04: Админы суурь (тохиргоо, audit log, хууль эрх зүйн хуудас)

**What to build:** Админ `/admin` хэсэгт нэвтэрч, платформын тохиргоог (кредитийн ₮ үнэ, шимтгэлийн хувь, referral хугацаа, payout босго г.м) засна. Админы бүх үйлдэл audit log-д бичигдэнэ. Үйлчилгээний нөхцөл, нууцлалын бодлого, багшийн гэрээг хувилбартай засаж нийтэлнэ.

**Blocked by:** 02

**Status:** done — эхний админыг үүсгэж, баримтуудын анхны хувилбарыг нийтлэх үлдсэн (доорх "Үлдсэн")

- [x] Админ эрх (`@Auth('ADMIN')`); эхний админыг CLI-ээр: `pnpm --filter @lms/api admin:grant <утас|имэйл>` (audit-д "систем" үйлдэл)
- [x] Settings: key-value, утгын төрөл шалгалттай (бүхэл тоо, min/max), өөрчлөлтийн түүхтэй (`setting_revisions`); `SettingsService.get(key)` бусад модульд
- [x] Анхдагч утгууд: 1 кредит = 1,000₮, шимтгэл 40% / 10%, referral 30 хоног, payout босго 50,000₮, кредит хүчинтэй 12 сар (`apps/api/src/admin/settings.registry.ts`)
- [x] Audit log: хэн, хэзээ, юу, өмнөх/дараах утга, IP — өөрчлөлттэй нэг transaction-д; `/admin/audit` хуудаслалттай
- [x] Хууль эрх зүйн хуудас: ноорог → нийтлэх (нийтэлсэн нь засагдахгүй), нийтэд `/legal/terms|privacy|teacher-agreement`, хуучин хувилбар `?version=N`
- [x] Хэрэглэгч нөхцөлийг зөвшөөрсөн хувилбар, огноог бүртгэх механизм (`POST /legal/:slug/accept {version}`, `GET /me/legal`, `LegalService.hasAcceptedCurrent()` — ticket 05-д)
- [x] Integration тест: админ бус хэрэглэгч хандах боломжгүй; тохиргоо өөрчлөхөд audit бичигдэнэ (`admin.spec.ts`, 13 тест)

## Үлдсэн

- [ ] Эхний админ: өөрийн утас/имэйлээр нэг удаа нэвтэрч, `pnpm --filter @lms/api admin:grant <утас|имэйл>` ажиллуулах. Production: Railway shell-д `node dist/cli/grant-admin.js <identifier>`.
- [ ] Үйлчилгээний нөхцөл, нууцлалын бодлого, багшийн гэрээний текстийг `/admin/legal`-д оруулж нийтлэх (хуулийн зөвлөхтэй). Багшийн гэрээ нийтлэгдээгүй бол ticket 05-ийн өргөдөл гаргах боломжгүй.
